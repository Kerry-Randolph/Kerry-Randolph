## now: that's what's up!

a free app for locals, coming soon to google play. point your phone at a flyer on a community bulletin board, and the event goes straight into your calendar or off to a friend. every flyer scanned joins a shared list of what's on around town.

- **built with:** flutter and dart, go, postgresql and postgis, next.js, aws
- **built how:** solo, with ai agents doing much of the hands-on work. claude code plans, builds and reviews, with several sessions working in parallel through github issues and pull requests. chatgpt and grok bring second opinions and independent audits. i set the direction, make the calls, and check the work.
